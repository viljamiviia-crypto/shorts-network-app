Shorts Network

A private publishing and analytics tool for its owner's YouTube channels.

What it is

Shorts Network is a small tool that runs on its owner's own computer. It uploads YouTube Shorts to the owner's channels and reads those channels' YouTube Analytics, so each new video can be improved based on how the previous ones performed.

It is not a public service: only the owner's own channels are connected to it.

How it uses Google sign-in

When a channel is connected, Google asks for permission to:

  • upload videos to the channel,
  • read the channel's basic information and video list, and
  • read the channel's YouTube Analytics reports.

The tool uses YouTube API Services. Details are in the privacy policy.
